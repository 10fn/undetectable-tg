## Установка
#### Wndows
- `npm i`
- `npm run build:win`
- В папке `dist` появится папка `win-unpacked`. В ней будет исполняемый файл `undetectable-tg.exe`
- Запускаем и даем необходимые разрешения

#### MacOS
- `npm i`
- `npm run build:mac`
- В папке `dist` появится папка будет установочный файл Undetectable-tg.dmg
- Открываем файл, в появившемся окошке, перетаскиваем приложение в папку Applications
- Запускаем и даем необходимые разрешения




## Быстрый старт
1. Запустите приложение
2. Используйте `⌘Cmd/Ctrl+⇧Shift+H` для показа/скрытия
3. Перемещайте окно с помощью `⌘Cmd/Ctrl+⇧Shift+M`
4. Настройте прозрачность через `⌘Cmd/Ctrl+⇧Shift+↑/↓`
5. Настройте масштаб с помощью `⌘Cmd/Ctrl + / ⌘Cmd/Ctrl -`
